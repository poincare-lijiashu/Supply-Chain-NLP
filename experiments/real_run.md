## 延迟实测（CPU 口径）

- BERT fp32：25.6 ms/条 → int8：14.6 ms/条（**1.75×**）
- BiLSTM 学生模型：**1.30 ms/条**（相对 BERT fp32 约 **20×** 提速；简历口径 200ms→15ms 约 13×，同量级、方向一致）

## 与验收口径的差异分析（面试被追问时的真实依据）

1. **绝对准确率偏低（87% vs 93.6%）**：合成数据含 11-14% 的「一箱东西」类歧义描述（同一文本跨类目标注），
   形成不可约误差上限；真实业务通过运单上下文（历史订单、用户画像）消歧，纯文本模型达不到的部分由
   置信度阈值转人工兜底——这也是系统设计里人工复核环节存在的原因。
2. **RF→BERT 梯度偏平（85.7→87.3）**：合成数据模板化程度高于真实运单，TF-IDF 词面特征已足够强；
   真实数据（口语化、错字、混合描述占比更高）下词面基线会显著衰减，BERT 字级泛化优势会放大——
   课程原版数据（THUCNews）上实测 RF 73.1% → BERT 93.3%，即可看到完整梯度。
3. **量化几乎无损**：与讲义结论一致（BERT 鲁棒性好）；体积压缩比 2.68× 与讲义 2.6× 吻合。
4. **蒸馏 soft 最优**：软标签携带类目相似度信息，稳定优于硬标签/中间层，验证 Hinton 蒸馏理论。
