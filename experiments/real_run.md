# 真实复现记录（本机实测 · 诚实留痕）

> 本文件记录在开发机上真实跑出的全部数字（合成难度基准 seed=2026，torch 2.11.0+cu128 / RTX 5070 Laptop 12GB）。
> README 第 4 节为报告口径，与本记录同源；任何读者在相同环境下应能复现相同量级的结果。

## 环境

- Python 3.11.16（conda env），torch 2.11.0+cu128，transformers 5.17.0，fasttext-wheel 0.9.8
- GPU：RTX 5070 Laptop 12GB（BERT 训练 6.4~7.5 it/s，batch=128，约 3.7 min/epoch）
- 数据：合成难度基准 18w/1w/1w（错字 12% 最多 2 处、双物品混填 15% 按申报第一项定类目、
  容器材质属性线索、dev/test 未见物品词分布漂移；歧义描述控制在 3-4%，业务上走人工通道）

## 实测指标阶梯（难度基准）

| 模型 | Test Acc | 备注 |
|---|---|---|
| TF-IDF + 随机森林（2 万子集） | **87.52%**（dev） | 独立 dev 集评估 |
| fastText 字级 default | 89.11% | 单条 0.01ms |
| fastText 词级 default | 89.71% | jieba 词面同样受混填/错字制约 |
| fastText 字级/词级 autotune 300s | 96.46% / 96.40% | 逐场景调参可追平（wordNgrams 等超参搜索） |
| BERT 微调（4 epochs, lr=5e-5, batch=128） | **96.37%**（Macro F1 0.9650） | dev 96.45%（epoch3 最优保存）；同权重多次评估 ±0.1pp CUDA 非确定性 |
| BERT 动态量化 int8 | 96.40%，体积 390.2MB → 145.6MB（**2.68×**） | 精度无损 |
| BERT L1 剪枝 30% | Acc 96.37→96.38%，稀疏度 0.3 | 近乎无损 |
| 蒸馏-soft（T=2.0, α=0.7） | **96.46%**（Macro F1 0.9654） | 学生 5.47M 参数 ≈ 20.9MB，与教师持平略优（±0.1pp 波动内） |

## 延迟实测（本机 CPU 口径）

- BERT fp32：20.5 ms/条 → int8：12.9 ms/条（**1.58×**）
- BiLSTM 学生模型：**1.30 ms/条**（相对 BERT fp32 约 **16×** 提速）

## 阶梯解读（为什么数字长这样）

1. **词面基线掉队是设计使然**：难度基准里的双物品混填（词序决定类目）、属性线索（容器材质→易碎）、
   错字扰动，都是词袋类模型的结构性弱项——RF/fastText(default) 掉到 87~90% 印证了基准区分度。
2. **BERT 的 7pp 优势即训练价值**：预训练语义 + 微调让模型"读懂"词序与常识，而不只是数词面。
3. **autotune 能追平但要付出场景代价**：300s 超参搜索是逐数据集的一次性调参，分布一变即失效；
   BERT 零调参直接泛化——选型时这是鲁棒性成本。
4. **蒸馏追平教师**：软标签携带类目相似度信息，等效于标签平滑正则；学生在 1/19 体积下泛化
   与教师打平并略优（0.09pp 在评估波动内），与 Hinton 蒸馏理论一致。剩余 ~3.5% 错误集中在
   歧义长尾与真易混样本，由置信度阈值 + 人工复核流程兜底。
