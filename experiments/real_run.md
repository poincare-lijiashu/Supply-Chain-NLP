## 环境

- Python 3.11.16（conda env），torch 2.11.0+cu128，transformers 5.17.0，fasttext-wheel 0.9.8
- GPU：RTX 5070 Laptop 12GB（BERT 训练 ~6 it/s，batch=128，约 6 min/epoch）
- 数据：合成难度基准 v1.3.1 18w/1w/1w，难点刻意打在词袋模型的结构盲区——
  **远距申报 6%**（申报词与物品隔干扰短语）、**长距容器线索 5%**、**否定翻转 4%**、
  **规格阈值 3%**（同核心词不同修饰语）、错字 12%×最多 2 处、相邻混填 12%（第二件 70%
  中性背景物品池）、馈赠句式（"给小孩寄的X"）、dev/test 未见物品词漂移、歧义 3-4%

## 延迟实测（本机 CPU 口径）

- BERT fp32：19.5 ms/条 → int8：13.2 ms/条（**1.47×**）
- BiLSTM 学生模型：**1.30 ms/条**（相对 BERT fp32 约 **15×** 提速）

## 阶梯解读（为什么数字长这样）

1. **结构盲区是基准的设计核心**：远距申报/长距线索要求模型跨越干扰短语绑定修饰关系，
   否定翻转要求组合语义翻转强特征——线性词袋模型**结构性无法表达**（不是"没调好"）。
   RF/fastText(default) 稳定在 86~89%，基准区分度成立。
2. **BERT 的 ~8-10pp 优势即训练价值**：预训练语义 + 自注意力长程组合，零调参消化全部结构难点。
3. **autotune 的边界**：300s 超参搜索可追平大部分，但组合语义残差仍在，且逐场景调参是持续成本。
4. **蒸馏打平教师**：软标签=标签平滑正则；学生在 1/19 体积、1/15 延迟下与教师打平。
   剩余 ~3.5% 错误集中在歧义长尾与真易混样本，由置信度阈值 + 人工复核流程兜底。
