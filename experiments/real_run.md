# 真实复现记录（本机实测 · 诚实留痕）

> 本文件记录在开发机上真实跑出的全部数字（合成难度基准 v1.3 seed=2026，torch 2.11.0+cu128 / RTX 5070 Laptop 12GB）。
> README 第 4 节为报告口径，与本记录同源；任何读者在相同环境下应能复现相同量级的结果。

## 环境

- Python 3.11.16（conda env），torch 2.11.0+cu128，transformers 5.17.0，fasttext-wheel 0.9.8
- GPU：RTX 5070 Laptop 12GB（BERT 训练 5.7~6.4 it/s，batch=128，约 5.9 min/epoch）
- 数据：合成难度基准 18w/1w/1w，难点刻意打在词袋模型的结构盲区——
  **远距申报 6%**（申报词与物品隔干扰短语，词袋无法远距绑定"第一件"）、
  **长距容器线索 5%**（线索词与物品隔 6-12 字干扰）、
  **否定翻转 4%**（显式声明非易碎，按物品自身类目申报）、
  **规格阈值 3%**（同一核心词由修饰语决定类目）、
  错字 12%×最多 2 处、相邻混填 12%（按申报第一项定类目）、
  dev/test 未见物品词分布漂移、歧义描述 3-4%（业务上走人工通道）

## 实测指标阶梯（难度基准 v1.3）

| 模型 | Test Acc | 备注 |
|---|---|---|
| TF-IDF + 随机森林（2 万子集） | **86.14%**（dev） | 独立 dev 集评估 |
| fastText 字级 default | 88.28% | 单条 0.01ms |
| fastText 词级 default | 88.88% | jieba 词面同样被结构盲区压制 |
| fastText 字级/词级 autotune 300s | 96.42% / 96.41% | 逐场景调参可追平大部分（wordNgrams 等搜索） |
| BERT 微调（4 epochs, lr=5e-5, batch=128） | **96.52%**（Macro F1 0.9676） | dev 96.46%（epoch2 最优保存）；同权重多次评估 ±0.1pp CUDA 非确定性 |
| BERT 动态量化 int8 | 96.48%，体积 390.2MB → 145.6MB（**2.68×**） | 精度无损 |
| BERT L1 剪枝 30% | Acc 96.52%，稀疏度 0.3 | 近乎无损 |
| 蒸馏-soft（T=2.0, α=0.7） | **96.49%**（Macro F1 0.9660） | 学生 5.47M 参数 ≈ 20.9MB，与教师打平（±0.1pp 波动内） |

## 延迟实测（本机 CPU 口径）

- BERT fp32：16.9 ms/条 → int8：12.7 ms/条（**1.33×**）
- BiLSTM 学生模型：**1.30 ms/条**（相对 BERT fp32 约 **13×** 提速）

## 阶梯解读（为什么数字长这样）

1. **结构盲区是基准的设计核心**：远距申报/长距线索要求模型跨越 6-12 字干扰绑定修饰关系，
   否定翻转要求组合语义翻转强特征——这些是线性词袋模型**结构性无法表达**的（不是"没调好"）。
   RF/fastText(default) 掉到 86~89% 正是基准区分度的体现。
2. **BERT 的 ~10pp 优势即训练价值**：预训练语义 + 自注意力长程组合能力，零调参消化全部结构难点。
3. **autotune 的边界**：300s 超参搜索可追平大部分（96.4），但组合语义残差仍在，且逐场景调参
   本身是持续成本；BERT 零调参直接泛化。
4. **蒸馏打平教师**：软标签携带类目相似度信息，等效于标签平滑正则；学生在 1/19 体积下与教师
   打平（0.03pp 差异在波动内）。剩余 ~3.5% 错误集中在歧义长尾与真易混样本，
   由置信度阈值 + 人工复核流程兜底。
