# v2 Badcase 补丁清单（P13 手测回流）

日期：2026-09-14　数据版本：v2.300k-d2（冻结，训练只读）
来源：用户前端手动测试 + 服务冒烟采集

## 清单

| 词/短语 | 现象 | 根因 | 处置通道 |
|---|---|---|---|
| 手表 | 其他/拒识 34.4%（低置信） | 词库漏收**裸词"手表"**（现有仅 智能手表/电话手表/运动手表 等复合词） | ①词库补 `手表→2`（syn: 腕表/机械表/石英表）——**需 d3 升版重训**；②当前低置信已由 `<0.6 转人工` 兜住 |
| 猪猪侠 | 食品生鲜 99.84%（**高置信错分**） | 动画/IP 专名 OOV，模型用"猪"字联想猪肉 | ①词库补头部 IP 词（奥特曼/汪汪队/超级飞侠/猪猪侠→7 或 8）——需 d3 重训；②护栏兜不住（超高置信），机制天花板，见下 |
| LM8UU（及 22212/DN50/CJX2 等裸型号） | 其他/拒识 92.5% | holdout NEAR 型号词，训练 0 出现 | **已治理**：OOV 中间带护栏（0.6~0.95 含未登录词→转人工），serving 生效，无需动数据 |
| 筋膜枪 | 数码家电 99.96% | **判对**：带电个护小电器→2（TAXONOMY 冻结规则），非缺陷 | 无需处理 |
| 厕所 | 日用家居 97.5% | 判对（模型泛化正确） | 可选：补词库稳住，非必须 |

## 三种处置通道（按生效条件分）

1. **serving 层（已生效，不碰数据）**：OOV 中间带护栏——拦"中等置信 + 未登录词"（LM8UU 类）。`OOV_GUARD=1` 默认开，`OOV_LOW/OOV_HIGH` 可调。
2. **词库补丁（需 d3 升版→重跑 30 万→重训教师+蒸馏→六尺回归）**：手表、IP 专名、以及后续手测再收集的词。**已训模型改词库不生效**（权重不变），必须重训。
3. **机制天花板（无解，只能人工）**：超高置信专名错分（猪猪侠 99.8%）——OOV 检测无法区分"正确陌生泛化（西瓜 99.99%）"与"错误高置信外推（猪猪侠）"，置信度阈值调再高也同时伤害正确项。唯一出路：词库收录 + 重训，或业务上接受此类低频项走人工。

## 建议

先把手测跑完一轮（攒够 badcase 一起进清单），再一次性升 d3 收口，避免为每个词重训一次。
