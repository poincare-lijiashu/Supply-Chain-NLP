## 5. 发现的问题（诊断结论，按严重度）

### 🔴 P1 级（必须修，改数据）
1. **业务必需词被 FAR 隔离 → 训练 0 教，模型靠联想乱猜**
   - FAR 词 轮椅/口罩/安全座椅/千斤顶/工业皮带/连花清瘟/螺母 等在训练 0 出现
   - 评测表现：口罩→运动、轮椅→运动、工业皮带→服饰、连花清瘟→食品（置信 0.79-1.0）
   - 根因：P5 选 FAR 时把"真实寄递高频词"当"泛化测试词"，两者混淆。寄递初审必须认识这些词，不该 0 教
2. **违禁规则词被 FAR 隔离（P3 规则失效）**：散装白酒/防晒喷雾/灭鼠药/管制刀具/活体 训练 0 教 → 散装白酒→食品（已确认训练 0 条）
3. **10 个词（焊条/牙膏/自行车等）虽在别名层但未入生成池 → 训练 0 样本**（已修，待重烧）

### 🟡 P2 级（优化方向）
4. **NEAR 型号串泛化失败**：'22212'/'LM8UU'/'CJX2'/'DN50'/'DZ47' → 判拒识 14（置信 0.62-1.0）。模型把"纯字母数字串"学成拒识，丢了工业型号常识。优化：训练中提升型号串样本比例 + 明确型号=工业
5. **歧义词默认分类偏差**：'移动电源'→数码（训练教"充电宝"）——NEAR 本意考换说法泛化，实际模型未泛化。优化：NEAR train_teach 覆盖更全、或在训练数据显式加"移动电源=违禁限寄（含锂电池）"样本
6. **混填歧义**：'工业皮带'与'皮带'——训练仅"皮带=服饰"，需混填样本（工业皮带）适度注入
7. **L4 长句仅 2%**：远距申报等长难例偏少，决赛 NEAR/FAR 里难例泛化弱

### 🟢 P3 级（观测）
8. **转人工率过低于实际业务**：test-ID 转人工 0.000——合成数据太"规矩"，真实乱填远超此。上线需真实 badcase 回流校准工作点

## 7. 结论

- **分布内能力：优（99.9% 级）**，校准好，违禁召回达标
- **泛化能力：中等**（FAR 86.2 / NEAR 75.0），且暴露的根本问题是**数据（FAR/NEAR 选词 + 生成池）而非模型**——修复数据后预计显著提升
- **核心行动 = 重烧数据（修复 P5 选词 + 生成池）+ 重训**，其它为增强项
