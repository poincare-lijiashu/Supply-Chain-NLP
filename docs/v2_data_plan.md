# v2 数据质量工程与重训计划（v2.2 定稿）

日期：2026-09-14　状态：**P0 已完成，P1 待审查冻结**

## 0. 背景：为什么必须重做数据

v1（2026-09-14 之前）模型在分布内测试集上 96.5%，但前端实测暴露系统性问题：

| 现象 | 实测证据 |
|---|---|
| 常见词高置信错分 | 西瓜→服饰 0.43、饮料→文件 1.00、葡萄→数码 0.94（学生模型） |
| 词库覆盖极薄 | 西瓜/葡萄/香蕉/饮料在 20 万条数据中出现 0 次；每类仅 16–20 个物品词 |
| 背景词无标签 | "胶带"出现 1942 次但只当陪衬词，标签在 10 类均匀分布，模型永远学不到它是什么 |
| 评测虚高 | 测试集与训练集同生成器同词库，96.5% 是分布内分数；无开放词汇评测 |
| 架构缺陷（已修） | BiLSTM 取 padding 末位，单条/批量结果不一致（已用 pack_padded_sequence 修复并有回归测试） |

**根因一句话**：v1 是"约 180 个词 × 16 个模板换序凑 18 万句、自己出题自己考"。

## 1. 业务定位（B2B）

物流公司内部寄件自动初审标记系统：输入托寄物描述自由文本 → 输出类目+置信度+处置建议（放行/转人工/拦截）。

指标优先级因此确定：
1. **违禁限寄召回率**（漏检是安全事故，一票否决）
2. 普通类目精度与转人工率的平衡（转人工=运营成本，必须度量、受控）
3. 分布外常识泛化（真实输单大量是 2–4 字裸词）
4. 推理成本（学生模型 1.3ms / 21MB 上线，BERT 教师不上线）

## 2. 数据质量六维度

| 维度 | v2 目标 |
|---|---|
| 覆盖度 | 15 类 × 三级本体，8000–10000 词位，每类 500–700 主词+别名/方言/型号 |
| 正确性 | 人审标签正确率 ≥99%；规则样本 100% 符合裁决手册 |
| 多样性 | 去重唯一率 ≥95%；单词在单类占比 ≤8%；句式 80–120 个 |
| 真实性 | 裸词（2–6 字）样本 30%；长度四档仿真；噪声层（错字/方言/英文夹杂/数字混写） |
| 边界清晰 | 25–30 条成文归类规则 + 冲突矩阵，每条规则可单元测试 |
| 可度量 | 六把独立评测尺，holdout 词训练集零泄漏（grep 硬断言） |

**量级原则**：种类覆盖 > 表达多样性 > 样本条数。30 万样本是"15 类 × 每类保底 2 万"的结果，不是为多而多；多样性不达标时加词加句式，禁止复制充数。

## 5. 六把评测尺子

| 评测集 | 考什么 | 规模 |
|---|---|---|
| dev | 训练调参 | 1.5 万（15 类均衡） |
| test-ID | 分布内精度（旧口径，可与 v1 对照） | 1.5 万 |
| test-NEAR | 近义泛化：训练有"苹果"无"蛇果/红富士"、有"螺栓"无"螺丝钉" | 每类 20–30 概念 × 多句式 |
| test-FAR | 常识未登录：西瓜/葡萄/胶带等整词预留，训练 0 出现 | 150–250 高频词 |
| test-REJECT | 拒识正确性：乱码/外文/脏话/无关文本/零信息描述 | 400–600 条 |
| test-SIM | 业务仿真：类目不均衡（违禁稀少）、裸词多、含真实输单噪声 | 1 万，单独标注"估计分布" |

指标口径：ID/NEAR/FAR 报 acc + macro-F1；13 类单独报**召回率/精确率**（安全指标）；14 类报转人工命中；SIM 集报转人工率（运营成本）。
